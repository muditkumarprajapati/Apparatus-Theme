# Apparatus Theme for Pterodactyl Panel (1.11.x - 1.15.x)

Cinematic Desert Sunset Parallax theme featuring:
- **Background Big Title**: `JTGPANEL`
- **Background Subtitle**: `CLOUD & INFRASTRUCTURE`
- **Login Card**: `ArixByte Login`
- Full GSAP 3.12 Parallax, Earth Shake Entrance, & Sine-wave floating dunes.
- **Blueprint Extension & Standalone Direct Injection Support**.

---

## ⚡ Quick One-Command Setup

Clone the repository to your server and launch the interactive manager:

```bash
git clone https://github.com/muditkumarprajapati/Apparatus-Theme.git /root/Apparatus-Theme
cd /root/Apparatus-Theme
sudo bash install.sh
```

### 📋 Interactive Menu:
```text
Select option [1-4]:
 [1] Install Theme
 [2] Update Theme
 [3] Remove Theme
 [4] Exit
```

---

## 📦 Blueprint Extension Installation (.blueprint)
If you run **Blueprint**:
```bash
cd /var/www/pterodactyl
blueprint -i /root/Apparatus-Theme/apparatus-theme.blueprint
```
